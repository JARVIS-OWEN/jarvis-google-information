Privacy notice

Draft for operator review · 25 October 2026

Purpose and access

JARVIS Gmail Test connects the operator’s own Google account to a personal assistant. Gmail access is read-only. Selected message headers and relevant message text support requested summaries and proposed actions. The configured Gmail tools do not send or delete mail, retrieve attachments or create Gmail drafts.

Calendar access supports reading agendas and requested event creation, editing and cancellation. Current action tools are limited to private, owned, single events on the configured test calendar. Background briefings read events only.

AI processing and sharing

Relevant selected email and calendar text may be sent to the operator’s existing OpenAI model for the assistant functions they have authorised. Model-service processing is governed by the applicable account controls and provider terms. JARVIS does not sell Google user data or use it for advertising. These assistant features do not train a JARVIS foundation model.

Storage and recovery

Assistant records and connection credentials are kept in operator-controlled local storage. Recovery archives may be copied to the operator’s encrypted cloud backup storage. Credentials, private messages and calendar contents are not published on this website.

Retention and control

The operator controls saved records and recovery copies. Revoking Google access stops future API access but does not itself erase previously saved summaries or backups. The operator can review and remove those records through their supported local recovery and file-management procedures.

Google access can be revoked through Google Account connections. Contact the operator using the support address shown on the Google consent screen.

This information website

The pages contain no forms, cookies set by the site, analytics scripts or assistant login. The information pages are intended for GitHub Pages hosting with a DuckDNS address. GitHub records visitor IP addresses for security purposes. DuckDNS provides DNS services and maintains its operator account and DNS records. These services do not receive mailbox contents, calendar contents or JARVIS credentials through this website. See the GitHub Privacy Statement and DuckDNS Privacy Statement.
